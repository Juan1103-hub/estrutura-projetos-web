# Catálogo de Templates

> Curadoria para o stack padrão: Next.js 16 + Tailwind v4 + shadcn/ui + TypeScript + Supabase + Prisma
> Última atualização: Jul/2026

---

## Como usar

1. IA identifica o perfil do projeto novo (Next.js App, Dashboard, Landing, etc.)
2. Consulta esta tabela por perfil
3. Clona o template mais adequado (ou usa local)
4. Remove arquivos específicos do template, aplica design tokens do workspace

---
