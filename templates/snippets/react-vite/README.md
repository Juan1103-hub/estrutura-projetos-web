# Templates — React SPA (Vite)

Templates prontos para copiar e adaptar em projetos React SPA.

---

## Como usar

1. Escolher o template pelo tipo (layout, form, table, etc.)
2. Copiar o componente para o projeto
3. Adaptar props, estilos e dados
4. Validar TypeScript e testes

## Templates disponíveis

| Arquivo | Descrição |
|---|---|
| `AppLayout.tsx` | Layout com sidebar + main content |
| `DataTable.tsx` | Tabela genérica com ordenação e paginação |
| `FormField.tsx` | Campo de formulário com validação |
| `Modal.tsx` | Modal reutilizável com focus trap |
| `LoadingSkeleton.tsx` | Skeleton de carregamento |
| `EmptyState.tsx` | Estado vazio com ícone e CTA |
