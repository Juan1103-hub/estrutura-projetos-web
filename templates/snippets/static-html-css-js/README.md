# Templates — HTML/CSS/JS Estático

Templates prontos para copiar e adaptar em projetos landing page / institucional.

---

## Como usar

1. Escolher o template pelo tipo (landing, form, pricing, etc.)
2. Copiar o trecho para o projeto
3. Adaptar textos, cores (usar variáveis CSS) e imagens
4. Validar acessibilidade (contraste, alt, labels)

## Templates disponíveis

| Arquivo | Descrição |
|---|---|
| `landing-hero.html` | Hero section com CTA |
| `pricing-cards.html` | Grid de planos/preços |
| `contact-form.html` | Formulário com validação |
| `footer.html` | Footer com links e redes sociais |
| `faq-accordion.html` | Perguntas frequentes com accordion |
| `testimonial-grid.html` | Depoimentos em grid |
| `cta-banner.html` | Banner de chamada para ação |
